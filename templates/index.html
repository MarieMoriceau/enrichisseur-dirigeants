📖 Mode d'emploi — comment lancer un enrichissement
  1. Télécharge le template Excel via 📥 Template, puis remplis 1 ligne par société (nom obligatoire ; siren, domaine, org_id, code_postal, ville… optionnels mais utiles).
  2. Glisse ton fichier dans la zone 📂 et vérifie le mapping des colonnes proposé.
  3. Saisis ton email (vérifie aussi tes spams) — plusieurs adresses possibles, séparées par des virgules.
  4. Choisis tes phases : par défaut les 5 sont cochées. Décoche-en pour un run partiel (debug, ou ne faire qu'une partie du pipeline).
  5. Clique sur ⚡ Lancer : le run part sur le serveur. Tu peux fermer l'onglet, il continue tout seul.
  6. Suis-le dans le panneau « Runs » : en cours, en attente, terminés. L'Excel arrive par email et reste téléchargeable depuis le panneau.

  • Pappers : base légale française (SIREN, domaine, représentants légaux actifs)
  • Claude+web : recherche web des dirigeants opérationnels (CEO, CFO, CTO, COO, DG, DRH, Partners…)
  • Pipedrive : check si la société/contacts existent déjà dans ton CRM
  • Kaspr : LinkedIn → email pro pour les contacts sans email
  • Fullenrich : batch final pour email + téléphone (multi-providers waterfall)
💡 Conseil : plus tu fournis d'infos en entrée (SIREN, domaine, code postal, ville), moins l'enrichisseur tâtonne et plus le résultat est précis.
⏱️ Patience : ~15-30 min pour 50 sociétés, ~1-2 h pour 200. Les runs s'exécutent un par un : si tu en lances un 2ᵉ, il attend son tour dans la file. Fermer l'onglet ne tue plus rien.
↻ Pas-à-pas : un run terminé peut être relancé sur d'autres phases (bouton « Relancer des phases ») en repartant de ses résultats actuels.
🚫 Cas qui peuvent rater : société radiée (signalée en rouge dans l'Excel), sociétés sans dirigeant identifiable (renvoyée vide), domaine introuvable (Fullenrich skip). Limites des sources de données, pas un bug.
